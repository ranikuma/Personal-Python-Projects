# Project 001: Hello World

## Description
A simple introductory project that demonstrates basic Python syntax and output.

## Learning Objectives
- Understand basic Python syntax
- Learn how to print output to the console
- Get familiar with running Python scripts

## How to Run

```bash
python main.py
```

## What It Does
This program prints a greeting message to the console and demonstrates basic string formatting.

## Concepts Covered
- Print statements
- String formatting
- Basic Python structure
