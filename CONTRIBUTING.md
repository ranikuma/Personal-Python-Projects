# Contributing to Personal Python Projects

This repository is a collection of 100 Python projects for programming practice.

## Project Structure

Each project should follow this structure:

```
projects/
└── project_XXX_name/
    ├── README.md          # Project description and instructions
    ├── main.py           # Main project file
    ├── requirements.txt  # Project-specific dependencies (if any)
    └── tests/           # Unit tests (optional)
```

## Adding a New Project

1. Create a new directory in the `projects/` folder with the format: `project_XXX_name`
   - XXX is the project number (001-100)
   - name is a descriptive name (use underscores for spaces)

2. Add a README.md file with:
   - Project title and description
   - Learning objectives
   - How to run the project
   - Example usage

3. Write your Python code in `main.py` or split into multiple files as needed

4. If your project requires external packages, add a `requirements.txt` file

5. Update the main README.md with your project information

## Code Guidelines

- Follow PEP 8 style guidelines
- Add comments to explain complex logic
- Include error handling where appropriate
- Write clean, readable code
