## 🚀 Getting Started

### Prerequisites

- Python 3.7 or higher
- pip (Python package manager)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ranikuma/Personal-Python-Projects.git
cd Personal-Python-Projects
```

2. Install common dependencies:
```bash
pip install -r requirements.txt
```

3. Navigate to any project and run it:
```bash
cd projects/project_001_hello_world
python main.py
```
